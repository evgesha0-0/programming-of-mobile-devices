# Промпт: общая техническая документация Smart Cat Feeder

Создай в ветке `dev` общую техническую документацию для параллельной разработки проекта Smart Cat Feeder. Перед началом проверь ветку, состояние репозитория и существующие файлы. Не изменяй `main`, не выполняй merge/rebase, не переписывай существующий README и не создавай программную реализацию.

Документация должна быть на русском языке; имена API, JSON-полей и идентификаторы — на английском. Все документы должны использовать одинаковые сущности, поля, статусы и пути. Не придумывай аппаратные характеристики, GPIO-пины или совместимость библиотек: модель Khadas, механизм и оборудование пометь как требующие уточнения.

Архитектура:

- backend: TypeScript, NestJS, PostgreSQL, централизованные данные, REST API, команды, состояния и история;
- Linux на Khadas: преимущественно TypeScript/Node.js, GPIO, механизм, датчик веса, локальное выполнение расписаний, REST API и локальное хранение при отсутствии сети; небольшой драйвер на C или C++ допустим только при подтверждённой аппаратной необходимости;
- Android: Java, Android SDK, расписания, ручные команды, состояние, история и уведомления.

Android взаимодействует только с backend. Khadas самостоятельно выполняет расписания; backend не запускает их повторно. Удалённые команды Khadas получает периодическим исходящим опросом backend.

Подготовь и согласуй:

1. `docs/architecture.md` с назначением, Mermaid-диаграммами, ответственностями, offline-режимом, ошибками и восстановлением связи.
2. `docs/api.md` с REST API `/api/v1`, едиными `snake_case`-полями, UTC/ISO 8601, локальным временем расписаний, авторизацией, идемпотентностью и единым форматом ошибок.
3. `docs/database.md` с логической моделью PostgreSQL для устройств, расписаний, ручных команд и кормлений без создания SQL-миграций.
4. `docs/workflow.md` с ответственностью веток и процессом Pull Request через `dev`.
5. `docs/testing.md` с десятью интеграционными сценариями и программной имитацией GPIO и датчика веса.

Добавь в README только ссылки на документы. Секреты в промпте и репозитории не сохраняй.
