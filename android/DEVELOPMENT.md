# Разработка Android-клиента

Работа выполнена с помощью Codex по запросу участника `@sheiiny`.
Существенный запрос: изучить проект Smart Cat Feeder и продолжить только Android-часть
на Java, оставив backend и базу данных другому участнику.
Сохранить участников проекта и историю их работы. Использовать существующий REST-контракт.

Первый этап: проект Android Studio, подключение к серверу, состояние кормушки,
ручные команды с безопасным повтором, расписания, история и проверки клиента.
Исходные сведения об участниках в корневом README не менялись.

Второй этап по запросу продолжить Android-часть: автоматическая проверка результата
ручного кормления при открытом приложении, уведомления о конечных результатах,
проверка соответствия ответа ожидаемой команде и тесты остановки/повторов опроса.
Backend и общий контракт не менялись.
