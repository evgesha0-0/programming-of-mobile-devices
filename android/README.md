# Smart Cat Feeder для Android

Android-клиент позволяет подключиться к кормушке через REST API, просматривать её состояние и историю кормлений, управлять расписаниями и безопасно запускать ручную выдачу корма.

## Возможности

- подключение к backend по адресу сервера, UUID кормушки и пользовательскому токену;
- просмотр состояния устройства с ручным обновлением;
- создание, изменение и удаление расписаний;
- просмотр истории кормлений с постраничной загрузкой;
- ручное кормление с подтверждением, защитой от повторной отправки и опросом результата;
- уведомления о завершении, ошибке или истечении срока ручной команды;
- возврат на экран подключения при истечении или отзыве токена.

## Требования

- Android Studio с Android SDK 35;
- JDK 17;
- устройство или эмулятор с Android 8.0 (API 26) либо новее;
- доступный backend Smart Cat Feeder и пользовательский токен формата `usr_` плюс 43 символа Base64URL.

Проект использует Gradle Wrapper 8.9 и Android Gradle Plugin 8.7.3, поэтому отдельно устанавливать Gradle не требуется.

## Сборка и запуск

Откройте каталог `android` как отдельный проект в Android Studio, дождитесь синхронизации Gradle и запустите конфигурацию `app` на устройстве или эмуляторе.

Сборка из терминала Windows:

```powershell
cd android
.\gradlew.bat assembleDebug
```

Сборка из терминала Linux или macOS:

```bash
cd android
./gradlew assembleDebug
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`. Release-вариант без подписи можно собрать командой `assembleRelease`; результат находится в `app/build/outputs/apk/release/app-release-unsigned.apk`.

## Подключение

На экране «Подключение» укажите:

1. Базовый адрес backend без пути, query-параметров и fragment, например `https://feeder.example.com`.
2. UUID кормушки в каноническом формате.
3. Пользовательский токен доступа.

В release-сборке разрешён только HTTPS. Debug-сборка дополнительно принимает HTTP для `localhost`, `127.0.0.1` и `10.0.2.2`. Для backend, запущенного на компьютере разработчика, Android Emulator обращается к нему через `10.0.2.2`, например `http://10.0.2.2:3000`.

После подключения адрес сервера и UUID сохраняются локально. Токен хранится только в памяти процесса и после перезапуска приложения вводится заново. Кнопка очистки удаляет сохранённые несекретные параметры и завершает текущую сессию.

## Работа с приложением

### Состояние

Экран показывает доступность кормушки, состояние механизма и сведения о последней синхронизации. Кнопка обновления повторно запрашивает данные у backend.

### Расписания

Для расписания задаются время, минимум один день недели, часовой пояс IANA, размер порции и признак активности. Существующие записи можно изменить или удалить после подтверждения.

### Ручное кормление

Перед отправкой приложение проверяет размер порции и запрашивает подтверждение. Каждая команда получает уникальный идентификатор и срок действия пять минут, поэтому повторная отправка того же запроса не создаёт вторую выдачу. После принятия команды приложение опрашивает её состояние и показывает итог. При временной ошибке доступны повторная проверка результата и безопасная повторная отправка исходной команды.

На Android 13 и новее приложение запрашивает разрешение на уведомления непосредственно перед ручным кормлением. Отказ не мешает выполнению команды, но итог будет виден только в приложении.

### История

История содержит плановые и ручные кормления, их статус, запрошенную и фактическую порцию, временные метки и сведения об ошибке. Следующая страница загружается по серверному курсору.

## Проверки

Запуск unit- и сквозных JVM-тестов:

```powershell
cd android
.\gradlew.bat testDebugUnitTest
```

Полная локальная проверка перед коммитом:

```powershell
cd android
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleRelease
```

HTML-отчёт тестов создаётся в `app/build/reports/tests/testDebugUnitTest/index.html`, отчёт Android Lint — в `app/build/reports/lint-results-debug.html`.

## Безопасность

- токен передаётся в заголовке `Authorization: Bearer ...` и не сохраняется на диске;
- экран подключения защищён от снимков экрана и показа в списке недавних приложений;
- резервное копирование данных приложения отключено;
- release-сборка запрещает незашифрованный HTTP-трафик;
- при ответе `401 Unauthorized` токен удаляется из памяти и требуется повторное подключение;
- не добавляйте реальные токены, UUID устройств и адреса закрытых серверов в исходный код, тесты и логи.

## Структура модуля

- `app/src/main/java/ru/smartcatfeeder` — UI, модели API, сетевой клиент и репозиторий;
- `app/src/main/res` — разметки, строки, стили, значки и сетевые политики;
- `app/src/test/java/ru/smartcatfeeder` — unit- и сквозные JVM-тесты Android-клиента.
