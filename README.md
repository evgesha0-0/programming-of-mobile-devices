## Тема проекта

**Автоматизированная система кормления домашних животных с мобильным управлением и контролем выдачи корма.**

## Задачи проекта

В ходе работы необходимо:

- разработать приложение для ОС Linux на встраиваемом компьютере Khadas;
- реализовать управление механизмом выдачи корма через GPIO;
- подключить датчик веса для контроля количества выданного корма;
- реализовать автоматическую выдачу корма по заданному расписанию;
- реализовать возможность ручной выдачи порции корма;
- разработать REST API для взаимодействия мобильного приложения с Khadas;
- разработать Android-приложение на Java для настройки кормушки и управления ей;
- реализовать настройку расписания кормления и размера порции через Android-приложение;
- реализовать отображение текущего состояния кормушки;
- реализовать хранение и просмотр истории кормлений;
- реализовать уведомления о выполненном кормлении и ошибках работы устройства;
- провести тестирование взаимодействия мобильного приложения, программного обеспечения Khadas и физических компонентов кормушки.

## Ожидаемый результат к декабрю 2026 года

К декабрю 2026 года планируется получить работающий прототип автоматической кормушки для домашних животных.

Прототип должен включать:

- встраиваемый компьютер Khadas под управлением Linux;
- механизм автоматической выдачи корма;
- датчик веса для контроля выдаваемой порции;
- программное обеспечение для управления исполнительными устройствами через GPIO;
- REST API для взаимодействия с мобильным приложением;
- Android-приложение для настройки расписания, размера порции и ручного запуска кормления;
- отображение состояния кормушки и истории кормлений.

Система должна поддерживать автоматическое кормление по расписанию и ручную выдачу корма по команде пользователя из Android-приложения.
