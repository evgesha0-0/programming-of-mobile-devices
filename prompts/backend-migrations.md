# Подготовка миграций backend

Работа выполнена с помощью Codex по запросу участника `@sheiiny`.
Запрос: разрешено продолжать не только Android, но и backend и другие части проекта;
сохранить участников и существующую историю работы.

Выбранный следующий этап: перенести согласованную модель из `docs/database.md`
в PostgreSQL, добавить повторяемый транзакционный запуск SQL-миграций, проверки
целостности данных, тесты и инструкцию запуска. Использован существующий каркас
Fastify и драйвер `pg`; HTTP-контракт и Android в этом этапе не менялись.
